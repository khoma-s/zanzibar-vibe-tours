### 1. Встроенный Responsive Test Panel

**Активация:**
- Добавьте `?test=1` к URL (например: `http://localhost:5173/?test=1`)
- Или нажмите `Ctrl+Shift+T` (Windows/Linux) / `Cmd+Shift+T` (Mac)

**Возможности:**
- Переключение между Desktop/Tablet/Mobile
- Визуальная проверка всех страниц
- Тестирование в iframe

**Открытие:** `F12` или `Ctrl+Shift+I` (Windows) / `Cmd+Opt+I` (Mac)

## 🐛 Известные проблемы и решения

### Проблема: Изображения не загружаются
**Решение:** Добавьте изображения в `public/images/` согласно структуре в INSTRUCTIONS.md

### Проблема: Текст выходит за границы на мобильных
**Решение:** Проверьте `line-clamp-2` и `line-clamp-3` классы в CSS

### Проблема: Lightbox не закрывается
**Решение:** Убедитесь, что `document.body.style.overflow` восстанавливается

### Проблема: Медленная загрузка изображений
**Решение:** Используйте `loading="lazy"` и оптимизируйте изображения (WebP, сжатие)

## 🚀 Автоматизация тестирования

### Скрипт для проверки всех страниц

Создайте файл `test-responsive.sh`:

```bash
#!/bin/bash

URLS=(
  "http://localhost:5173/it/"
  "http://localhost:5173/it/tour"
  "http://localhost:5173/it/hotel"
  "http://localhost:5173/it/galleria"
  "http://localhost:5173/it/blog"
  "http://localhost:5173/it/chi-siamo"
)

DEVICES=(
  "iPhone SE"
  "iPad Air"
  "Desktop"
)

echo "Starting responsive tests..."

for url in "${URLS[@]}"; do
  for device in "${DEVICES[@]}"; do
    echo "Testing $url on $device"
    # Добавьте сюда вызов Lighthouse CLI или другого инструмента
  done
done

echo "Tests completed!"
```

### Lighthouse CI

```bash
# Установка
npm install -g @lhci/cli@latest

# Запуск
```
