# Изображения моментов (Moments)

Эта папка содержит фотографии для секции "Nasze chwile" / "I nostri momenti" на странице About.

## Структура

```
public/images/moments/
├── photo1.jpg  # Фото момента 1
├── photo2.jpg  # Фото момента 2
├── photo3.jpg  # Фото момента 3
├── photo4.jpg  # Фото момента 4
└── photo5.jpg  # Фото момента 5
```

## Требования

- Формат: JPG или PNG
- Рекомендуемый размер: минимум 800x600px
- Соотношение сторон: 4:3 или 16:9
- Максимальный размер файла: 500KB

## Использование

Эти фотографии отображаются в слайдере на странице About в секции "Nasze chwile" (польский) / "I nostri momenti" (итальянский).

При клике на фото открывается lightbox с возможностью навигации между изображениями.
