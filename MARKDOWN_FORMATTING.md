# 📝 Форматирование текста в статьях блога

## Поддерживаемый Markdown-синтаксис

В файлах `posts.json` (как для итальянской, так и для польской версии) теперь поддерживается базовое Markdown-форматирование.

### Жирный текст
Используйте двойные звёздочки для выделения **жирным**:

```json
{
  "text": "Это **жирный текст** в статье"
}
```

Результат: Это **жирный текст** в статье

### Курсив
Используйте одинарные звёздочки для *курсива*:

```json
{
  "text": "Это *курсивный текст* в статье"
}
```

Результат: Это *курсивный текст* в статье

### Комбинированное форматирование
Можно комбинировать жирный и курсив:

```json
{
  "text": "Это **жирный и *курсивный* текст**"
}
```

Результат: Это **жирный и *курсивный* текст**

### Переносы строк
Используйте `\n` для переноса строки:

```json
{
  "text": "Первая строка\nВторая строка\nТретья строка"
}
```

## Пример использования

```json
{
  "post_id": "001",
  "title": "10 najpiękniejszych plaż Zanzibaru",
  "text": "Zanzibar słynie z **rajskich plaż**. Oto nasz ranking:\n\n1. **Nungwi** — najsłynniejsza plaża z *najbielszym piaskiem*\n2. **Kendwa** — idealna do *relaksu*\n\nWięcej informacji znajdziesz na naszej stronie.",
  "category": "Porady"
}
```

## Где применяется форматирование

Форматирование Markdown применяется в двух местах:

1. **Превью статьи** (первые 150 символов) — отображается на странице блога
2. **Полный текст статьи** — отображается в модальном окне при клике на статью

## Важные замечания

- Форматирование работает только в поле `text`
- Заголовки (`title`) не поддерживают Markdown
- Категория (`category`) не поддерживает Markdown
- Markdown-синтаксис должен быть правильно экранирован в JSON (используйте `\n` для переносов строк)

## Технические детали

Функция `parseMarkdown()` в `BlogPage.tsx` преобразует:
- `**текст**` → `<strong>текст</strong>` (жирный)
- `*текст*` → `<em>текст</em>` (курсив)
- `\n` → `<br/>` (перенос строки)

Результат отображается через `dangerouslySetInnerHTML`, что позволяет рендерить HTML-теги.
