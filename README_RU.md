## 📖 Обзор проекта

**Zanzibar Vibe Tours** - это двуязычный (итальянский/польский) туристический сайт для продвижения туров на Занзибар.

### Основные возможности:
- ✅ Две языковые версии: итальянская (/it/) и польская (/pl/)
- ✅ Автоматическое определение языка браузера
- ✅ Адаптивный дизайн для всех устройств
- ✅ Динамическая загрузка изображений из папок
- ✅ Markdown форматирование для статей блога
- ✅ Централизованное управление контактами

### 1. kontakts.json - Контактная информация

**Путь:** `public/data/kontakts.json`

Этот файл содержит все контактные данные, которые используются на всём сайте.

```json
{
  "tel": "+255 777 123 456",
  "email": "info@zanzibarvibetours.com",
  "whatsapp": "393475849637",
  "address": "Zanzibar, Tanzania",
  "facebook": "https://www.facebook.com/1172238702643016",
  "instagram": "https://www.instagram.com/kuzdravioletta",
  "tiktok": "https://www.tiktok.com/@violetta.kuzdra"
}
```

**Поля:**
- `tel` - номер телефона (отображается в футере и CTA секции)
- `email` - email адрес (отображается в футере и CTA секции)
- `whatsapp` - номер WhatsApp без "+" (используется для ссылок wa.me)
- `address` - адрес (отображается в футере)
- `facebook` - ссылка на Facebook страницу
- `instagram` - ссылка на Instagram профиль
- `tiktok` - ссылка на TikTok профиль

### 2. tours.json - Туры

**Путь:** `public/data/it/tours.json` и `public/data/pl/tours.json`

```json
[
  {
    "tour_id": "001",
    "img_title": "/images/tours/001/title.jpg",
    "imgs": "/images/tours/001/",
    "info": "Полное описание тура...",
    "currency": "EUR",
    "price": 1500,
    "title": "Название тура",
    "short_desc": "Краткое описание",
    "key_points": "Пункт 1,Пункт 2,Пункт 3",
    "duration": "1-3 дни",
    "group": "2-10 osób",
    "location": "Zanzibar, Tanzania"
  }
]
```

**Поля:**
- `tour_id` - уникальный идентификатор тура (используется в URL)
- `img_title` - путь к главному изображению тура
- `imgs` - путь к папке с изображениями тура (все фото из этой папки будут показаны в галерее)
- `info` - полное описание тура (поддерживает Markdown)
- `currency` - код валюты: "EUR" (€) или "PLN" (zł)
- `price` - цена тура (число)
- `title` - название тура
- `short_desc` - краткое описание для карточки
- `key_points` - ключевые моменты тура, разделённые запятыми (отображаются как теги)
- `duration` - продолжительность тура
- `group` - размер группы
- `location` - местоположение

**Важно:**
- Валюта берётся из поля `currency`, а не определяется по языку
- Все изображения из папки `imgs` автоматически загружаются в галерею тура
- `key_points` разделяются запятыми без пробелов после запятой

- `odescription` - описание отеля (в карточке показывается до 300 символов)
- `key_points` - ключевые особенности отеля, разделённые запятыми

**Важно:**
- Все изображения из папки `imgs` автоматически загружаются в галерею отеля
- Описание автоматически обрезается до 300 символов с добавлением "..."
- `key_points` отображаются как теги под описанием

- Рекомендуется 800×600px

- Формат: MP4, WebM
- Рекомендуется разрешение 1280×720 или выше

**Общие требования:**
- Максимальный размер файла: 500KB для фото, 100KB для иконок
- Оптимизируйте изображения для веба
- Используйте WebP формат для лучшей производительности (опционально)

## 📝 Markdown форматирование

В статьях блога (`posts.json`) поддерживается базовое Markdown форматирование.

### Жирный текст
Используйте двойные звёздочки: `**жирный текст**`

**Пример:**
```json
{
  "text": "Это **жирный текст** в статье"
}
```

**Результат:** Это **жирный текст** в статье

### Курсив
Используйте одинарные звёздочки: `*курсивный текст*`

**Пример:**
```json
{
  "text": "Это *курсивный текст* в статье"
}
```

**Результат:** Это *курсивный текст* в статье

### Комбинированное форматирование
Можно комбинировать жирный и курсив:

**Пример:**
```json
{
  "text": "Это **жирный и *курсивный* текст**"
}
```

**Результат:** Это **жирный и *курсивный* текст**

### Переносы строк
Используйте `\n` для переноса строки:

**Пример:**
```json
{
  "text": "Первая строка\nВторая строка\nТретья строка"
}
```

### Полный пример статьи с Markdown:

```json
{
  "post_id": "001",
  "title": "10 najpiękniejszych plaż Zanzibaru",
  "text": "Zanzibar słynie z **rajskich plaż**. Oto nasz ranking:\n\n1. **Nungwi** — najsłynniejsza plaża z *najbielszym piaskiem*\n2. **Kendwa** — idealna do *relaksu*\n\nWięcej informacji znajdziesz na naszej stronie.",
  "category": "Porady"
}
```

## ❓ Часто задаваемые вопросы

### Q: Как добавить новое изображение в галерею?
**A:** Просто поместите файл в папку `public/images/gallery/`. Сайт автоматически обнаружит и отобразит его. Не нужно редактировать `gallery.json`.

### Q: Как удалить изображение из галереи?
**A:** Просто удалите файл из папки `public/images/gallery/`. Сайт автоматически перестанет его отображать.

### Q: Почему мои туры не отображаются?
**A:** Проверьте:
1. Валидность JSON файла (используйте https://jsonlint.com/)
2. Наличие всех обязательных полей
3. Правильность путей к изображениям
4. Отсутствие пропущенных запятых в JSON

### Q: Как изменить валюту для тура?
**A:** Измените поле `currency` в `tours.json`:
- `"EUR"` - для евро (€)
- `"PLN"` - для польских злотых (zł)
- `"USD"` - для долларов ($)
- `"GBP"` - для фунтов (£)

### Q: Как добавить больше фото к туру?
**A:** Просто поместите дополнительные фото в папку тура (например, `public/images/tours/001/`). Все фото автоматически появятся в галерее тура.

### Q: Почему кнопка WhatsApp не работает?
**A:** Проверьте:
1. Правильность номера в `kontakts.json` (без "+")
2. Наличие интернета на устройстве
3. Установлен ли WhatsApp на устройстве

### Q: Как изменить количество отображаемых туров на главной странице?
**A:** В файле `src/pages/HomePage.tsx` найдите строку:
```typescript
.then(data => setTours(data.slice(0, 4)))
```
Измените число `4` на нужное количество.

### Q: Как изменить количество случайных фото в галерее на главной странице?
**A:** В файле `src/pages/HomePage.tsx` найдите строку:
```typescript
setGalleryImages(shuffled.slice(0, 5));
```
Измените число `5` на нужное количество.

### Q: Как изменить количество случайных статей на главной странице?
**A:** В файле `src/pages/HomePage.tsx` найдите строку:
```typescript
setPosts(shuffled.slice(0, 3));
```
Измените число `3` на нужное количество.
