# 📱 Тестирование на реальных устройствах

## 🎯 Обзор

Этот документ содержит инструкции по тестированию сайта **Zanzibar Vibe Tours** на реальных мобильных устройствах и планшетах.

---

## 📲 Локальное тестирование

### Вариант 1: Локальная сеть (рекомендуется)

#### Шаг 1: Найдите IP-адрес вашего компьютера

**macOS:**
```bash
ipconfig getifaddr en0
```

**Windows:**
```bash
ipconfig
```
Найдите "IPv4 Address" (например: 192.168.1.100)

**Linux:**
```bash
hostname -I
```

#### Шаг 2: Запустите сервер с доступом из локальной сети

```bash
npm run dev -- --host
```

Сервер запустится на `http://0.0.0.0:5173`

#### Шаг 3: Откройте на мобильном устройстве

1. Убедитесь, что устройство подключено к той же Wi-Fi сети
2. Откройте браузер на устройстве
3. Перейдите по адресу: `http://[YOUR_IP]:5173`
   
   Пример: `http://192.168.1.100:5173`

#### Шаг 4: Добавьте в закладки

Сохраните URL для быстрого доступа при тестировании.

---

### Вариант 2: Ngrok (публичный доступ)

Если нужно протестировать вне локальной сети:

#### Установка Ngrok
```bash
# macOS
brew install ngrok

# Windows (Chocolatey)
choco install ngrok

# Или скачайте с https://ngrok.com/download
```

#### Запуск
```bash
# Терминал 1: Запустите dev server
npm run dev

# Терминал 2: Запустите ngrok
ngrok http 5173
```

Ngrok предоставит публичный URL (например: `https://abc123.ngrok.io`)

#### Использование
1. Откройте предоставленный URL на любом устройстве
2. Тестируйте сайт как на продакшене
3. Ngrok показывает запросы в веб-интерфейсе: `http://localhost:4040`

---

### Вариант 3: Vercel/Netlify (быстрый деплой)

#### Vercel
```bash
npm install -g vercel
vercel
```

#### Netlify
```bash
npm install -g netlify-cli
netlify deploy --prod
```

Получите публичный URL для тестирования.

## 📱 Тестирование на iOS

### Подготовка устройства

1. **Обновите iOS** до последней версии
2. **Установите Safari** (по умолчанию)
3. **Включите Web Inspector:**

1. Подключите iPhone/iPad через USB

## 📱 Тестирование на Android

### Подготовка устройства

1. **Обновите Android** до последней версии
2. **Установите Chrome** (по умолчанию)
3. **Включите USB Debugging:**
   - Настройки → О телефоне → Номер сборки (7 раз)
   - Настройки → Разработчик → USB отладка (ВКЛ)

### Подключение к компьютеру

1. Подключите устройство через USB
2. Откройте Chrome на компьютере
3. Перейдите: `chrome://inspect/#devices`
4. Разрешите отладку на устройстве
5. Выберите страницу для инспекции

### Тестирование

#### Chrome Android
- [ ] Все стили отображаются корректно
- [ ] Touch-события работают
- [ ] Клавиатура не ломает layout
- [ ] Address bar не перекрывает контент
- [ ] Scroll плавный
- [ ] Изображения загружаются
- [ ] Видео воспроизводится

#### Особое внимание

- **Разрешения:** HD, FHD, QHD
- **Ориентация:** Portrait/Landscape

## 📊 Тестовые сценарии

### Сценарий 1: Первый визит

1. Откройте главную страницу
2. Проверьте загрузку (<3 сек)
3. Проверьте hero-секцию
4. Прокрутите вниз
5. Проверьте все секции

### Сценарий 2: Навигация

1. Откройте меню (mobile) или навигацию (desktop)
2. Перейдите на каждую страницу
3. Проверьте загрузку
4. Вернитесь назад
5. Проверьте scroll position

### Сценарий 3: Переключение языков

1. Нажмите IT/PL
2. Проверьте изменение URL
3. Проверьте изменение контента
4. Проверьте сохранение языка в localStorage
5. Перезагрузите страницу
6. Проверьте сохранение языка

### Сценарий 4: Галерея

1. Откройте галерею
2. Нажмите на изображение
3. Проверьте lightbox
4. Используйте стрелки для навигации
5. Закройте lightbox (Esc или клик)
6. Проверьте на touch-устройствах (swipe)

### Сценарий 5: Форма

1. Прокрутите до footer
2. Введите email в newsletter
3. Отправьте форму
4. Проверьте валидацию
5. Проверьте на разных клавиатурах (iOS/Android)

## 🐛 Отладка на устройствах

### iOS Safari

#### Remote Debugging
1. Подключите iPhone к Mac
2. Safari → Разработка → [Устройство]
3. Выберите страницу
4. Используйте DevTools как на desktop

#### Console Log
```javascript
// Добавьте в код для отладки
console.log('Device:', navigator.userAgent);
console.log('Screen:', window.screen.width, window.screen.height);
console.log('Viewport:', window.innerWidth, window.innerHeight);
```

### Android Chrome

#### Remote Debugging
1. Подключите Android к компьютеру
2. Chrome → `chrome://inspect/#devices`
3. Выберите устройство и страницу
4. Используйте DevTools

#### Console Log
```javascript
// То же самое для Android
console.log('Device:', navigator.userAgent);
console.log('Screen:', window.screen.width, window.screen.height);
console.log('Viewport:', window.innerWidth, window.innerHeight);
```

## 🎯 Производительность на устройствах

### Метрики

#### Время загрузки
- **3G:** <5 сек
- **4G:** <3 сек
- **WiFi:** <2 сек

#### First Contentful Paint (FCP)
- **Хорошо:** <1.8 сек
- **Требует улучшения:** 1.8-3.0 сек
- **Плохо:** >3.0 сек

#### Largest Contentful Paint (LCP)
- **Хорошо:** <2.5 сек
- **Требует улучшения:** 2.5-4.0 сек
- **Плохо:** >4.0 сек

#### Cumulative Layout Shift (CLS)
- **Хорошо:** <0.1
- **Требует улучшения:** 0.1-0.25
- **Плохо:** >0.25

### Инструменты

#### Lighthouse Mobile
```bash
# Chrome DevTools
F12 → Lighthouse → Device: Mobile

# CLI
lighthouse https://yoursite.com --preset=perf
```

#### WebPageTest
1. Откройте https://www.webpagetest.org/
2. Выберите.location (ближайший к вам)
3. Device: Motorola G (pow8)
4. Connection: 4G
5. Запустите тест
